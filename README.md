# Walmart Sales Analysis Dashboard
Excel dashboard and exploratory data analysis of Walmart sales.
## Project Overview

This project presents an exploratory data analysis (EDA) of Walmart weekly sales using Microsoft Excel. The aim of the project was to clean the dataset, perform descriptive statistical analysis, explore sales trends, and develop an interactive dashboard to communicate key business insights. The project demonstrates practical data analysis techniques and the use of Excel for transforming raw data into meaningful information.

## Dataset

The dataset was downloaded from Kaggle:https://www.kaggle.com/datasets/mikhail1681/walmart-sales?resource=download
The dataset contains 6,435 records and includes the following variables:
- Store
- Date
- Weekly_Sales
- Holiday_Flag
- Temperature
- Fuel_Price
- CPI
- Unemployment
## Objectives
The objectives of this project were to:
- Clean and prepare the dataset for analysis.
- Perform descriptive statistical analysis.
- Conduct exploratory data analysis (EDA).
- Identify the highest-performing stores.
- Compare holiday and non-holiday sales.
- Analyze monthly sales trends.
- Examine the relationship between temperature and weekly sales.
- Design an interactive Excel dashboard.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Data Analysis ToolPak
- Dashboard Design

## Data Cleaning
The following data cleaning steps were completed:

- Converted numeric values stored as text into numeric format.
- Converted the Date column into Excel date format.
- Created a Month column from the Date field.
- Checked for formatting inconsistencies.
- Prepared the dataset for analysis and visualization.
## Descriptive Statistics
The following statistics were calculated for Weekly Sales:

- Mean (Average)
- Median
- Minimum
- Maximum
- Standard Deviation
- Range
These statistics provided an understanding of the distribution and variation of weekly sales across all stores.

## Exploratory Data Analysis
The project answered the following business questions:

- Which store generated the highest total sales?
- Which month recorded the highest sales?
- Do holiday weeks have higher sales than non-holiday weeks?
- Does temperature affect weekly sales?
- Which variables are most strongly related to weekly sales?

## Dashboard
The interactive dashboard includes:

- KPI Cards
- Sales by Store
- Monthly Sales Trend
- Holiday vs Non-Holiday Sales
- Temperature vs Weekly Sales
- Slicers for interactive filtering
